- Fundamentos de JavaScript
- Variáveis e operadores
- Estruturas condicionais
- Estruturas de repetição
- Funções
- Manipulação de dados
- Lógica de programação
- HTML e CSS

## Projetos e exercícios

- Exercícios organizados por aulas
- Analisador de números
- Loja de teste
- Práticas de programação e desenvolvimento web

## Tecnologias utilizadas

- JavaScript
- HTML
- CSS

## Objetivo

Registrar minha evolução nos estudos de programação, praticando conceitos de JavaScript e desenvolvimento web por meio de exercícios e pequenos projetos.
